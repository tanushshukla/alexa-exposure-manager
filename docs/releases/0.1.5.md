# Alexa Exposure Manager 0.1.5

## Fixed

- The setup warning shown when no previous Alexa YAML was captured no longer
  says to use exposure controls "below" when the manager is not active yet.
- The warning now gives the actual fresh-start sequence: add the managed
  includes displayed on the setup card, run Home Assistant's configuration
  check, restart Home Assistant, and then configure exposure in the manager.
- Configured installations use equivalent guidance without implying that the
  includes always need to be added again.

## Compatibility

- Home Assistant `2026.6.4` or newer (tested through `2026.8.1`).
- HACS `2.0.5` or newer.

## Installation / upgrade

In HACS, open **Alexa Exposure Manager** and download `0.1.5`, then restart Home
Assistant. The versioned panel URL loads the corrected frontend after restart.

No managed YAML contents or exposure choices are changed by this release.
