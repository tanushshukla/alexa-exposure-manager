# Alexa Exposure Manager 0.1.9

## Preview first, save from the review

The main action is now **Preview changes**, from Entities, Filter rules, and
Settings alike. It opens one modal showing the entire shared draft:

- Entities becoming exposed or hidden and future-entity behavior.
- Added/removed rules, duplicate removals, and rule-order changes.
- Alexa name, description, and category edits.
- Explicit exception removal through Use rules and missing-reference cleanup.
- Expandable resulting filter and entity-configuration YAML.

Preview writes nothing. **Save changes** appears only inside the modal after a
successful current preview. **Back to editing** or Escape keeps your draft;
editing again requires a fresh preview. Failed previews offer Retry preview.
The separate inline filter-preview button is removed.

Existing native precedence, administrator/read-only protections, revision
checks, paired backups, validation/rollback, and cleanup inventory checks remain
unchanged. This update does not reset configuration or delete devices.

## Update through HACS

Take a full Home Assistant backup, download **0.1.9** through HACS, restart Home
Assistant, then refresh the panel. No re-import or configuration reset is needed.
After saving, follow the restart guidance and run Alexa discovery when needed.

Requires Home Assistant 2026.6.4 or newer and HACS 2.0.5 or newer.
