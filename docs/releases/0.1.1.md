# Alexa Exposure Manager 0.1.1

## Highlights

- Fixes panel screen flicker caused by reloading on every Home Assistant state
  update. The panel now loads once per websocket connection and only reloads
  after a reconnect.

## Compatibility

- Home Assistant `2026.6.4` or newer (tested through `2026.8.1`).
- HACS `2.0.5` or newer.

## Installation / upgrade

In HACS, open **Alexa Exposure Manager** and download `0.1.1`, then restart
Home Assistant and hard-refresh the browser.

## Upgrade notes

No configuration changes are required for this patch. If you are still on the
one-time setup screen, complete migration import before switching
`alexa.yaml` to the managed includes, then restart.
