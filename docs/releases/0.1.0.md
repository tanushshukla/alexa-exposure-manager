# Alexa Exposure Manager 0.1.0

Status: release candidate notes prepared; no tag or GitHub release published.

## Highlights

- Home Assistant-native, administrator-only exposure management for the manual
  Alexa Smart Home Skill.
- Real entity, device, and area data with support determined by Home Assistant's
  Alexa adapters.
- Simple exposed or hidden state plus **Expose new entities** behavior.
- Migration preview for legacy entity, domain, and glob filters using Home
  Assistant filter precedence.
- Alexa-specific name, description, and ordered display-category editing.
- Bulk exposure workflow with count-based confirmation.
- Revision-protected deterministic saves with five retained backup versions,
  atomic two-file replacement, full configuration validation, and automatic
  rollback.
- Explicit restart-required workflow and Alexa discovery instructions.
- Advanced YAML preview, backup restore, missing-entry review, read-only safety,
  redacted diagnostics, and separately warned full-YAML support export.

## Compatibility

- Home Assistant `2026.6.4`.
- Home Assistant `2026.7.4`.
- Home Assistant `2026.8.1`.
- HACS `2.0.5` or newer.

## Installation

Add `https://github.com/tanushshukla/alexa-exposure-manager` as a HACS custom
repository with category **Integration**, download `0.1.0`, restart Home
Assistant, and add **Alexa Exposure Manager** from **Settings > Devices &
services**.

Do not install until the release is actually published and the repository
contains `custom_components/alexa_exposure_manager`.

## Required Configuration

`configuration.yaml`:

```yaml
alexa: !include alexa.yaml
```

`alexa.yaml`:

```yaml
smart_home:
  locale: en-US
  filter: !include alexa_exposure_filter.yaml
  entity_config: !include alexa_entity_config.yaml
```

Keep existing proactive-event settings and credentials in the user-owned Alexa
configuration. The integration owns only the two included files.

## Before Upgrading or Migrating

- Create a full Home Assistant backup.
- Copy the existing Alexa configuration and included filter/entity configuration
  files.
- Review the migration preview before confirming it.
- Keep the old files until restart and real Alexa discovery have been verified.

## Known Boundaries

- Requires an already working manual Alexa Smart Home Skill and AWS setup.
- Does not manage Home Assistant Cloud Alexa exposure.
- Does not edit advanced domain or glob rules after migration.
- Does not automatically restart Home Assistant or trigger Alexa discovery.
- Does not merge concurrent manual YAML edits.
- Does not allow non-administrator access.
