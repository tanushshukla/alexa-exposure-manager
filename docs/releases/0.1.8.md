# Alexa Exposure Manager 0.1.8

## Native filters and safe cleanup

- Edit all six native Alexa filter sections, including domains and globs, with
  exposure-impact previews before saving (#59).
- See why an entity is exposed and select **Use rules** to remove explicit
  entity exceptions without deleting Alexa metadata (#60).
- Preview and selectively stage exact duplicate rules and missing explicit
  references, individually or together (#61–#63). Unselected duplicates and
  ordering are retained. Missing means absent from both registry and current
  states; inventory is rechecked during Save.
- Access paired-backup recovery in Settings, with local timestamps, health
  checks, and protection against discarding pending edits (#64).
- Use integrated Entities / Filter rules / Settings navigation, shared
  Save/Discard, mobile layouts, and keyboard-accessible confirmation (#65).

All edits remain staged until Save. Cleanup never deletes Home Assistant or
Amazon devices and never resets or rewrites the containing Alexa configuration.
An empty native filter uses Home Assistant's registry defaults, not deny-all.

## Reliability fixes

Preserve explicit exception intent against changed native rules, including bulk
actions after Use rules. Preserve pending mode conversion and metadata when
entering native editing. Reload authoritative rules/reasons after every save and
lock editing during save/restore. Reject stale exposure previews.

## Update through HACS

1. Take a full Home Assistant backup before updating.
2. Refresh/download updates in HACS and install **0.1.8**.
3. Restart Home Assistant to load the new backend and panel.
4. Reload the Alexa Exposure Manager page (hard-refresh if the old panel remains).
5. Test your rules with Preview before Save. Existing managed YAML and containing
   Alexa configuration do not need to be reset or re-imported for this update.

After saving exposure changes, follow the panel's restart guidance and run Alexa
discovery when needed. Keep a known-good backup while testing.

## Verification and limitations

42 frontend tests and 92 backend tests passed, alongside lint, formatting,
type checks, production build, and disposable HA 2026.8.1 browser acceptance.
The live run covered rules, Use rules, cleanup, keyboard confirmation, paired
restore, and mobile layouts; it did not call Amazon/AWS or verify real device
discovery. Owner testing in Home Assistant follows this release. See
`docs/ACCEPTANCE.md` for evidence and scope.

Requires Home Assistant 2026.6.4 or newer and HACS 2.0.5 or newer.
